# Курсы валют

Справочное Flutter Web-приложение для сравнения валютных курсов и пересчёта
сумм. Каталог валют и курсы загружаются в браузере напрямую из
[Frankfurter](https://frankfurter.dev/); серверная часть не используется —
готовая сборка представляет собой статический каталог файлов.

## Возможности

- Каталог активных валют Frankfurter с поиском по коду и названию.
- Единая таблица с постоянной базой EUR: сумма (по умолчанию 1), список валют
  с курсом и двумя результатами, форма добавления валюты внизу. Одна введённая
  сумма одновременно пересчитывается из EUR в валюту строки и из валюты
  строки в EUR. Например, при сумме 100 и курсе 25 CZK за EUR результаты
  равны 2 500,00 CZK и 4,00 EUR.
- Изменение суммы пересчитывает все строки без новых запросов. Ввод принимает
  запятую или точку и разделители тысяч; неверная сумма показывает ошибку.
- Валюты можно добавлять и удалять; для каждого внешнего курса видны источник
  и дата публикации. Строка EUR рассчитывается в обоих направлениях
  с курсом 1 без обращения к источнику.
- Выбранный список таблицы, его порядок и пустой список сохраняются в браузере (`localStorage`)
  для того же сайта и профиля до очистки данных сайта; настройки не
  синхронизируются между браузерами или устройствами. Сумма и загруженные
  курсы не сохраняются; при открытии сумма снова равна 1. Прежний сохранённый
  выбор базы игнорируется: список остаётся, а база всегда равна EUR.
- При ошибке обновления ранее загруженные курсы остаются доступными с явным
  предупреждением; повтор запроса — кнопкой «Обновить».
- Светлый минималистичный русскоязычный интерфейс, адаптированный к мобильным
  экранам, клавиатурной навигации и экранным дикторам.

## Требования

- Flutter 3.47.2 (Dart 3.13.2) — версии, с которыми проект проверяется в CI.
- [Task](https://taskfile.dev/) — опционально, для коротких команд `task …`;
  все действия выполняются и прямыми командами `flutter`.

## Запуск

```sh
flutter pub get
task serve
```

`task serve` эквивалентна `flutter run -d web-server`. Dev-сервер использует
постоянный адрес из `web_dev_config.yaml`; после запуска откройте
<http://localhost:8080> в обычном окне браузера — окно автоматически не
открывается. Пользуйтесь тем же браузером и профилем: тогда список валют
сохраняется после остановки и повторного запуска приложения.

Конфигурация `main.dart` в GoLand/IntelliJ также запускает `web-server`.
Нажмите Run и откройте адрес выше. В этом режиме возможности отладки
ограничены. Для отладки через Chrome можно убрать дополнительные аргументы
конфигурации и выбрать устройство Chrome, но Flutter использует временный
профиль и переносит его данные при завершении; остановка из IDE может
прервать этот перенос.

Файл `web/index.html` — шаблон Flutter: не открывайте его напрямую через
`file://`.

Команды эквивалентны `flutter analyze` и `flutter test`. Каждый push и

## Развёртывание

Серверной части нет: production-сборка — статический каталог файлов.

```sh
flutter build web --release
```

Содержимое каталога `build/web` размещается на любом статическом хостинге
(nginx, GitHub Pages, объектное хранилище и т.п.). Специфичный хостинг и
публикация в этом проекте не настроены — выбор хостинга остаётся за вами.

Перед публикацией сборку можно проверить локально:

```sh
python3 -m http.server 8080 --directory build/web
```

После запуска статического сервера приложение доступно по адресу
<http://localhost:8080>.

## Ограничения данных

- Frankfurter публикует ежедневные справочные курсы, а не предложения банка
  или обменного пункта.
- Комиссии, спред и задержки конкретного провайдера не учитываются.
- Расчёт выполняется локально с `double` и предназначен для справочной оценки,
  а не бухгалтерских операций.
- Для загрузки данных требуется доступ браузера к `api.frankfurter.dev`;
  сетевые ошибки можно повторить кнопкой «Обновить».

## Тема оформления

По умолчанию выбран режим «Авто»: светлая тема от восхода до заката и тёмная ночью.
Приложение запрашивает разрешение браузера на геолокацию и рассчитывает положение
Солнца локально. Координаты остаются в памяти вкладки: приложение не сохраняет их
и не отправляет внешним API. Геолокация доступна по HTTPS и на localhost.

Пока координаты определяются, а также при отказе, тайм-ауте или ошибке расчёта
используется системная тема. Причина показана в меню темы рядом с кнопкой обновления.
Повторный выбор «Авто» повторяет попытку. Палитра проверяется раз в минуту и сразу
после возврата к вкладке; при возврате также обновляется местоположение.

В меню можно выбрать постоянную «Светлую» или «Тёмную» тему. Все три режима
сохраняются в том же браузере и профиле; прежний ручной выбор сохраняет свой смысл.
При недоступном хранилище текущий выбор действует до закрытия страницы.
Смена палитры сохраняет сумму, список валют, курсы и фокус ввода.
