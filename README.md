# Курсы валют

Светлое минималистичное Flutter Web-приложение для сравнения справочных
валютных курсов и пересчёта сумм. Каталог и курсы загружаются напрямую из
[Frankfurter](https://frankfurter.dev/) в браузере; серверная часть не
используется.

Базовая валюта и выбранный список таблицы сохраняются в браузере для того же
сайта и профиля до очистки данных сайта. Настройки не синхронизируются между
браузерами или устройствами. Сумма, пара конвертера и загруженные курсы не
сохраняются.

## Требования

Проверено с Flutter 3.47.2 и Dart 3.13.2.

## Запуск

```sh
rtk flutter pub get
rtk flutter run -d web-server
```

После запуска откройте <http://localhost:8080> в обычном окне браузера.
Dev-сервер использует постоянный адрес из `web_dev_config.yaml`. Пользуйтесь
тем же браузером и профилем: тогда список валют сохраняется после остановки
и повторного запуска приложения.

Конфигурация `main.dart` в GoLand/IntelliJ также запускает `web-server`.
Нажмите Run и откройте адрес выше; браузер автоматически не запускается.
В этом режиме возможности отладки ограничены. Для отладки через Chrome
можно убрать дополнительные аргументы конфигурации и выбрать устройство
Chrome, но Flutter использует временный профиль и переносит его данные
при завершении; остановка из IDE может прервать этот перенос.

Файл `web/index.html` — шаблон Flutter: не открывайте его напрямую через `file://`.

## Проверка и сборка

```sh
flutter analyze
flutter test
flutter build web --release
python3 -m http.server 8080 --directory build/web
```

После запуска статического сервера приложение доступно по адресу
<http://localhost:8080>. Публикация на хостинг в этом проекте не настроена.

## Ограничения данных

- Frankfurter публикует ежедневные справочные курсы, а не предложения банка
  или обменного пункта.
- Комиссии, спред и задержки конкретного провайдера не учитываются.
- Расчёт выполняется локально с `double` и предназначен для справочной оценки,
  а не бухгалтерских операций.
- Для загрузки данных требуется доступ браузера к `api.frankfurter.dev`;
  сетевые ошибки можно повторить кнопкой «Обновить».

## Результаты проверки

5 сентября 2026 года выполнены `flutter analyze` без замечаний, 45 тестов и
release-сборка. Сборка проверена через локальный статический сервер в Chrome:
каталог и запросы EUR → CZK вернули HTTP 200 без CORS- и runtime-ошибок, курс
`24,2190` за 5 сентября 2026 года дал `72 657,00 CZK` для `3000 EUR`. Ручное
обновление повторило оба запроса, а при отключённой сети прежние данные
сохранились с явным предупреждением.

В release-сборке изменение базы на CZK и удаление всех валют таблицы записались
в `localStorage`; пустой список и база восстановились после перезагрузки страницы
и после полного повторного запуска Chrome с тем же профилем.

Дополнительно проверен запуск через `web-server`: после удаления GBP и добавления
JPY сервер полностью остановлен и запущен заново. После перезагрузки страницы
в том же профиле восстановился список USD, CZK, JPY. Все 46 тестов прошли.

Desktop-компоновка проверена при 1440 × 1200 px, мобильная — при ширине 360 px;
widget-тест также проверяет 200% размер текста без ошибок раскладки. Поиск и
выбор валюты клавиатурой, видимое состояние фокуса и live-region результата
проверены widget-тестом и через accessibility tree Chrome.
