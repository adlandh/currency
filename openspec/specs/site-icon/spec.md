# Spec: site-icon

## Purpose

Favicon веб-приложения «Курсы валют»: вместо иконки Flutter по умолчанию сайт использует собственную SVG-иконку с символом валюты, соответствующую визуальной идентичности приложения.

## Requirements

### Requirement: Собственный favicon с символом валюты

Веб-приложение SHALL использовать в качестве favicon SVG-изображение с символом евро (€) на скруглённой плашке акцентного цвета приложения. Страница SHALL ссылаться на него через `<link rel="icon" type="image/svg+xml">`. Файл иконки по умолчанию Flutter (favicon.png) SHALL NOT поставляться и SHALL NOT использоваться страницей.

#### Scenario: Загрузка сайта

- **WHEN** пользователь открывает сайт приложения в браузере
- **THEN** во вкладке браузера отображается SVG-иконка с символом € на плашке фирменного цвета, а не иконка Flutter по умолчанию

#### Scenario: Прямой запрос иконки

- **WHEN** браузер запрашивает `/favicon.svg`
- **THEN** сервер возвращает SVG-изображение с корректным content-type `image/svg+xml` (или эквивалентным)

#### Scenario: Иконка в сборке и деплое

- **WHEN** выполняется сборка (`flutter build web`) и деплой (`task deploy`)
- **THEN** favicon.svg попадает в собранное приложение и на сервер, а favicon.png в сборке отсутствует

#### Scenario: iOS-иконки не затронуты

- **WHEN** приложение добавляют на домашний экран iOS или открывают установленный PWA
- **THEN** используются PNG-иконки из `icons/` (apple-touch-icon и manifest.json), которые остаются неизменными
